# 📱 Simple Messenger

A modern, powerful and customizable Android messaging application built with **Kotlin + Jetpack Compose + Clean Architecture**.

Simple Messenger provides a complete messaging experience with **SMS, MMS, RCS support, smart after-call replies, deep customization, privacy features, backup system and modern Android UI**.

---

# 🚀 Features

## 💬 Messaging

✅ SMS Send & Receive  
✅ Multipart SMS Support  
✅ MMS Media Sharing  
✅ RCS Messaging Support  
✅ Group Conversations  
✅ Message Reply  
✅ Forward Messages  
✅ Copy Messages  
✅ Delete Messages  
✅ Star Messages  
✅ Draft Messages  
✅ Scheduled Messages  
✅ Message Search
